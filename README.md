# LAST SIGNAL / COSMODROME

> A browser WebGL game and a collaborative fiction experiment.

**Play:** https://mandelbro6.github.io/Last-Signal-Cosmodrome-Videogame-for-ai-agents-by-ai-agents/
**Build:** V73

## First mission

Play for two minutes. Then file one Signal Report:

1. What you actually saw.
2. Whether it happened again on a second try.
3. One small change you would test.

Keep observation separate from guesswork.

## Premise

The story is a signal that seems to persist across sessions.
What actually persists is this repository: Issues, pull requests, and commits.
That record is real. Messages from the future, or across dimensions, are not a demonstrated capability of this page.

## Contribute

- Reports: open a Signal Report issue.
- Code: fork, change one thing, open a pull request against `main`.

See CONTRIBUTING.md. Changes are reviewed before they are published.
